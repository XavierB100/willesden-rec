# Historical preview catalogue

The 252-listing preview catalogue was retired for the owner-approved 1.1.0 release on 24 October 2026. Its repeated fixtures, build flags and separate storefront adapter were removed.

The site now uses 14 admin-editable demo records in the same database as the existing catalogue, retaining half of the source photo sets. See [current demo stock, photo sources and removal](demo-stock.md) and [release notes](releases.md). The historical preview remains documented in [change history](change-history.md).
